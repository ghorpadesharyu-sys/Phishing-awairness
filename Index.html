Phishing Awareness Simulation

A local demonstration project for studying how users react to common phishing cues.

Safety notice: This application does not send email, contact external services, or store passwords. Any data entered on the demonstration login page is immediately discarded.

Learning objectives

  • Recognize urgency, account-warning and credential-request cues.
  • Measure clicks, demonstration data-entry attempts and reports.
  • Practice safer responses such as verifying through a known channel.

Open Simulation Email

Ethical use

Run the simulation only with informed consent. Do not impersonate a real company, collect real credentials, send unsolicited messages, or deploy the page outside an authorized classroom/lab environment.

Project title: “Phishing Awareness Simulation Using Social Engineering Techniques”
